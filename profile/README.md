# reversi-brain プロジェクト

オセロ（リバーシ）の最強AIと、それを使って遊べるWeb/モバイルアプリの開発プロジェクトです。

## 🌐 リポジトリ構成（マルチレポ）

当プロジェクトは、機能ごとにリポジトリを分けて開発しています。

* [api](./../../../../api) - Python (FastAPI) 製のAI思考エンジン ＆ バックエンド
* [web](./../../../../web) - Webブラウザで遊べるフロントエンド
* [ios](./../../../../ios) - iOSモバイルアプリ（予定）
* [Android](./../../../../android) - Androidモバイルアプリ（予定）

## 🛠️ 技術スタック
- **Backend:** Python, FastAPI
- **Infra:** さくらのVPS, Nginx, Let's Encrypt
